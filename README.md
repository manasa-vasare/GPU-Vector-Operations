# GPU Vector Operations

## Objective
The objective of this project is to implement and analyze vector operations on the GPU using CUDA, comparing the performance with sequential execution.

## Team Members
- Manasa Vasare

## How to Build and Run
1. Navigate to the `src` directory.
2. Compile the sequential and parallel source codes using standard C/C++ compilers and `nvcc` for CUDA code.
3. Run the executables.

## Results Summary
The parallel execution on the GPU shows significant speedup compared to the sequential execution. Detailed execution times and speedup graphs can be found in the `graphs` and `results` directories. A comprehensive analysis is provided in the `report` directory.
